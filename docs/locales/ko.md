
노르웨이 트론헤임에 거주하는 시니어 시스템 소프트웨어 엔지니어입니다. 지난 10여 년간 초저지연 원격 측정(telemetry) 파이프라인, 결정론적 실시간 통신 프로토콜, 고신뢰 시스템 아키텍처 구축에 집중해 왔습니다. 업무 외 시간 연구로는 역능(capability) 기반의 실험적 마이크로커널, 힙 할당 없는(zero-allocation) 모듈러 DSP 엔진, 미니멀한 명령줄 도구를 개발하고 있습니다.

제1원리(First-Principles)에 입각하여 엄격한 메모리 격리, 데이터 레이스 없는 결정론적 동시성 제어, CPU 캐시와의 기계적 공감(Mechanical Sympathy), 그리고 프레임워크 유행을 뛰어넘는 견고한 엔지니어링을 지향합니다.

---

## 🧭 핵심 엔지니어링 원칙

- **핫 패스(Hot Path) 내 동적 할당 원천 배제**: 빈번하게 호출되는 고속 처리 루프 내부에서 동적 힙 할당을 수행하는 것은 명백한 이유가 입증되기 전까지 아키텍처 결함으로 간주합니다.
- **결정론적 동시성 및 데이터 레이스 원천 차단**: 공유 상태 락(lock)에 의존하기보다 무락(lockless) 링 버퍼, 단일 생산자-단일 소비자(SPSC) 큐, 역능 기반 메시지 패싱을 기본 모델로 채택합니다.
- **최고 처리량보다 예측 가능한 지연 시간 우선**: 초당 10만 건을 처리하더라도 간헐적으로 2초의 테일 레이턴시가 튄다면, 실시간 정밀 제어 시스템에서는 치명적인 결함입니다.
- **기계적 공감(Mechanical Sympathy)**: 컴파일러 추론에 기대지 않고 L1/L2 캐시 라인 정렬, 분기 예측기 동작, 메모리 버스 대역폭을 설계 단계부터 정밀하게 고려합니다.
- **설계 기반 보안(Secure-by-Design)**: 엄격한 경계 격리, 상수 시간(constant-time) 암호화 연산, 외부망 없는 독립 빌드 재현성을 철저히 지킵니다.

## 🧰 기술 스택 매트릭스

### 시스템 및 프로그래밍 언어
- **주력 언어**: Rust (core, `no_std`, 임베디드 베어메탈), Modern C++ (C++20/23, 템플릿 메타프로그래밍, SIMD 연산), Zig (크로스 컴파일 툴체인, 런타임 인터페이스), C99/C11 (POSIX 인터페이스, 하드웨어 드라이버).
- **보조 및 스크립팅**: POSIX Shell, Python 3 (벤치마킹 리그, 신호 시뮬레이션, 텔레메트리 시각화), Lua 5.4 (임베디드 스크립팅).
- **어셈블리**: x86_64, AArch64, ARM Cortex-M (베어메탈 부팅 루틴, 컨텍스트 스위칭 원어 코드).

### 아키텍처, 커널 및 개발 도구
- **디버깅 및 프로파일링**: QEMU, GDB / LLDB, Linux perf, valgrind, Linux eBPF, FreeBSD bhyve.
- **툴체인 및 빌드 시스템**: Clang/LLVM, GCC 크로스 컴파일러, cargo, ninja, make.
- **하드웨어 및 신호 계측**: Saleae Logic Pro 16 로직 분석기, Siglent SDS1104X-E 오실로스코프, JTAG/SWD 디버그 프로브 (ST-Link, J-Link), I2C/SPI/CAN 프로토콜 분석기.

### 통신 프로토콜 및 스토리지
- **바이너리 프로토콜**: 제로카피 Cap'n Proto, FlatBuffers, CAN / UART / UDP 기반 커스텀 바이너리 프레임워크.
- **스토리지 엔진**: 로그 구조 병합(LSM) 트리, 메모리 매핑(mmap) 링 버퍼, Raw NVMe 블록 직접 디스패치.

## 📈 현재 연구 및 탐구 과제

- `float-OS`의 비동기 프로세스 간 역능 핸드셰이크에 대한 TLA+ 정형 명세 작성 및 검증.
- 리소스가 제약된 Cortex-M4 타깃에서의 다성(polyphonic) 웨이브테이블 오실레이터용 고정소수점(fixed-point) 연산 루틴 구현.
- 동적 런타임 종속성 없이 순수 독립형 ELF 바이너리를 직접 방출하는 초경량 셀프 호스팅 컴파일러 백엔드 구축.
