```text
             |___/         |_____|            
  "네트워크 케이블 없이 차가운 실리콘 위에서 홀로 구동되지 못한다면, 그것은 프로그램이 아니라 서비스에 불과하다."
```

노르웨이 트론헤임에 거주하며 저수준 시스템 소프트웨어를 개발하고 하드웨어를 연구하는 엔지니어입니다. 낮에는 저지연 원격 측정(telemetry) 파이프라인과 결정론적 실시간 통신 모듈을 설계하고, 밤에는 역능(capability) 기반의 실험적 마이크로커널, 힙 할당 없는(zero-allocation) 오디오 신디사이저, 작고 견고한 CLI 도구를 만듭니다.

메모리를 소중히 다루고, 고부하 환경에서도 예측 가능하게 작동하며, 반짝 유행하는 프레임워크 생태계보다 더 오래 살아남는 소프트웨어를 지향합니다.

---

## 🧭 엔지니어링 철학

- **핫 패스(Hot Path) 내 동적 할당 원천 배제**: 핵심 루프 내부에서 동적 힙 할당자를 호출한다면, 명백한 이유가 입증되기 전까지는 아키텍처 결함으로 간주합니다.
- **최고 처리량보다 예측 가능한 지연 시간 우선**: 초당 10만 건을 처리하더라도 통제되지 않는 2초의 테일 레이턴시(Tail Latency)가 발생한다면, 실제 물리 시스템 제어에서는 망가진 소프트웨어입니다.
- **기계적 공감(Mechanical Sympathy)**: 컴파일러를 탓하기 전에 캐시 라인이 어떻게 정렬되는지, 분기 예측기가 어떻게 추론하는지, 메모리 컨트롤러의 병목이 어디에 있는지 먼저 파악합니다.
- **오프라인 퍼스트 및 독립 구동**: 모든 도구는 격리된 빌드 환경에서 완전히 빌드되어야 하며, 외부 클라우드 원격 측정에 의존하지 않고 온전히 독립 실행되어야 합니다.

## 🧰 기술 스택 매트릭스

### 시스템 및 프로그래밍 언어
- **주력 언어**: Rust (core 크레이트, `no_std`, 임베디드 베어메탈), Modern C++ (C++20/23, 템플릿 메타프로그래밍, SIMD 연산), Zig (크로스 컴파일 및 런타임 인터페이스), C99/C11 (POSIX 인터페이스, 디바이스 드라이버 레이어).
- **보조 및 스크립팅**: POSIX Shell, Python 3 (벤치마킹 분석, 데이터 시각화, 신호 시뮬레이션), Lua 5.4 (임베디드 엔진 스크립팅).
- **어셈블리**: x86_64, AArch64, ARM Cortex-M (베어메탈 부팅 코드, 컨텍스트 스위칭 루틴).

### 커널, 임베디드 및 개발 도구
- **커널 및 런타임 분석**: QEMU, GDB / LLDB, perf, valgrind, Linux eBPF, FreeBSD bhyve.
- **컴파일러 및 툴체인**: Clang/LLVM 툴체인, GCC 크로스 컴파일러, cargo, ninja, make.
- **하드웨어 및 신호 분석**: Saleae Logic Pro 16 로직 분석기, Siglent SDS1104X-E 오실로스코프, JTAG/SWD 디버그 프로브 (ST-Link, J-Link), I2C/SPI 버스 패킷 분석.

### 네트워크 프로토콜 및 스토리지
- **바이너리 프로토콜**: 제로카피 Cap'n Proto, FlatBuffers, CAN / UART / UDP 기반 커스텀 바이너리 프레임워크.
- **스토리지 엔진**: 로그 구조 병합(LSM) 트리, 메모리 매핑(mmap) 링 버퍼, Raw NVMe 블록 직접 디스패치.

## 📈 현재 연구 및 탐구 주제

- `float-OS`의 비동기 프로세스 간 역능 핸드셰이크에 대한 정형 검증(TLA+ 명세 작성).
- 리소스가 극도로 제한된 Cortex-M4 타깃에서의 다성(polyphonic) 웨이브테이블 오실레이터용 고정소수점(fixed-point) 연산 최적화.
- libc 링킹 없이 순수 독립형 ELF 바이너리를 직접 생성하는 초경량 셀프 호스팅 컴파일러 백엔드 실험.
