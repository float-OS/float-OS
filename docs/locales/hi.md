# नमस्ते, मैं एदान वैन्स (`@float-OS`) हूँ 🛠️

```text
  _   _             _             ___  ____  
 | | | | ___ _   _  | |_ ___      / _ \/ ___| 
 | |_| |/ _ \ | | | | __/ _ \    | | | \___ \ 
 |  _  |  __/ |_| | | || (_) |   | |_| |___) |
 |_| |_|\___|\__, |  \__\___/_____\___/|____/ 
             |___/         |_____|            
  "यदि कोई सॉफ़्टवेयर बिना नेटवर्क के सिर्फ़ ठंडे सिलिकॉन पर नहीं चल सकता, तो वह एक सेवा है, प्रोग्राम नहीं।"
```

मैं ट्रॉनहैम, नॉर्वे में स्थित एक सिस्टम सॉफ़्टवेयर इंजीनियर और हार्डवेयर निर्माता हूँ। दिन में मैं कम-विलंबता (Low-latency) टेलीमेट्री पाइपलाइन और नियतात्मक वास्तविक समय संचार मॉड्यूल डिज़ाइन करता हूँ; रात में मैं प्रायोगिक क्षमता-आधारित माइक्रोकर्नल (Capability-based microkernels), शून्य-आवंटन ऑडियो सिंथेसाइज़र और कॉम्पैक्ट कमांड-लाइन टूल बनाता हूँ।

मैं ऐसे सॉफ़्टवेयर में विश्वास करता हूँ जो मेमोरी का सम्मान करता है, भारी लोड के तहत अनुमानित व्यवहार करता है और आधुनिक फ़्रेमवर्क के अल्पकालिक रुझानों से अधिक समय तक टिकता है।

---

## 🧭 इंजीनियरिंग दर्शन

- **हॉट पाथ में शून्य आवंटन (Zero Allocation in the Hot Path)**: यदि आंतरिक लूप किसी डायनामिक हीप आवंटक को कॉल करता है, तो इसे तब तक एक आर्किटेक्चरल बग माना जाता है जब तक कि अन्यथा सिद्ध न हो जाए।
- **कच्चे थ्रूपुट से अधिक अनुमानित विलंबता**: 100,000 req/sec को संभालने वाला लेकिन अनियंत्रित 2-सेकंड की टेल लेटेंसी वाला सिस्टम वास्तविक दुनिया के नियंत्रण के लिए अनुपयोगी है।
- **मैकेनिकल सहानुभूति (Mechanical Sympathy)**: कंपाइलर को दोष देने से पहले समझें कि कैश लाइनें कैसे संरेखित होती हैं, शाखा भविष्यवक्ता कैसे काम करते हैं, और मेमोरी कंट्रोलर कहाँ बाधा डालता है।
- **ऑफ़लाइन फर्स्ट और आत्मनिर्भर**: सभी टूल अलग-अलग वातावरण में पूरी तरह से बनने चाहिए और बिना किसी बाहरी क्लाउड टेलीमेट्री के सुचारू रूप से चलने चाहिए।

## 🧰 तकनीक मैट्रिक्स

### सिस्टम और प्रोग्रामिंग भाषाएं
- **प्राथमिक भाषाएँ**: Rust (core क्रेट्स, `no_std`, एम्बेडेड बेयर-मेटल), Modern C++ (C++20/23, टेम्प्लेट मेटाप्रोग्रामिंग, SIMD), Zig (क्रॉस-कंपाइलेशन टूलचेन, रनटाइम इंटरफ़ेस), C99/C11 (POSIX इंटरफ़ेस, डिवाइस ड्राइवर)।
- **सहायक और स्क्रिप्टिंग**: POSIX Shell, Python 3 (बेंचमार्क विश्लेषण, डेटा प्लॉटिंग, सिग्नल सिमुलेशन), Lua 5.4 (एम्बेडेड इंजन स्क्रिप्टिंग)।
- **असेंबली**: x86_64, AArch64, ARM Cortex-M (बेयर-मेटल बूट कोड, संदर्भ स्विचिंग)।

### कर्नल, एम्बेडेड और विश्लेषण उपकरण
- **कर्नल और रनटाइम विश्लेषण**: QEMU, GDB / LLDB, perf, valgrind, Linux eBPF, FreeBSD bhyve.
- **कंपाइलर और टूलचेन**: Clang/LLVM टूलचेन, GCC क्रॉस-कंपाइलर, cargo, ninja, make.
- **हार्डवेयर और सिग्नल विश्लेषण**: Saleae Logic Pro 16 लॉजिक एनालाइजर, Siglent SDS1104X-E ऑसिलोस्कोप, JTAG/SWD डिबग जांच (ST-Link, J-Link), I2C/SPI बस स्निफ़िंग।

## 📈 वर्तमान अनुसंधान और अन्वेषण

- `float-OS` में अतुल्यकालिक अंतर-प्रक्रिया क्षमता हैंडशेक के लिए TLA+ औपचारिक विनिर्देश लिखना।
- संसाधन-सीमित Cortex-M4 लक्ष्य पर पॉलीफोनिक वेव-टेबल ऑसिलेटर्स के लिए फिक्स्ड-पॉइंट अंकगणित अनुकूलन।
- बिना libc से लिंक किए सीधे स्टैंडअलोन ELF बायनेरिज़ उत्सर्जित करने वाले न्यूनतम सेल्फ-होस्टिंग कंपाइलर बैकएंड का प्रयोग।
