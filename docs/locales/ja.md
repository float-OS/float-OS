# こんにちは、エイダン・ヴァンス（`@float-OS`）です 🛠️

```text
  _   _             _             ___  ____  
 | | | | ___ _   _  | |_ ___      / _ \/ ___| 
 | |_| |/ _ \ | | | | __/ _ \    | | | \___ \ 
 |  _  |  __/ |_| | | || (_) |   | |_| |___) |
 |_| |_|\___|\__, |  \__\___/_____\___/|____/ 
             |___/         |_____|            
  "ネットワークケーブルなしで冷たいシリコンの上で動かせないなら、それはプログラムではなく単なるサービスにすぎない。"
```

ノルウェーのトロンハイムを拠点に、低レイヤーのシステムソフトウェアとハードウェアの研究開発を行っているエンジニアです。昼間は低遅延のテレメトリパイプラインと決定論的リアルタイム通信モジュールの設計を行い、夜間はケイパビリティベースの実験的マイクロカーネル、ヒープ割り当てゼロ（zero-allocation）のオーディオシンセサイザー、コンパクトで堅牢なCLIツールを開発しています。

メモリを尊重し、高負荷下でも予測可能に動作し、流行り廃りの激しいフレームワークよりも長く生き残るソフトウェアを追求しています。

---

## 🧭 エンジニアリング哲学

- **ホットパスにおける動的割り当ての完全排除**: インナーループで動的ヒープアロケータを呼び出すコードは、明確な妥当性が証明されない限りアーキテクチャ上のバグとみなします。
- **ピークスループットよりも予測可能なレイテンシ**: 秒間10万リクエストを捌けても、制御不能な2秒のテールレイテンシが生じるシステムは、実世界の物理制御においては破綻しています。
- **メカニカル・シンパシー（機械への共感）**: コンパイラを疑う前に、キャッシュラインがどう整列しているか、分岐予測がどう動いているか、メモリコントローラのボトルネックがどこにあるかを把握します。
- **オフラインファースト＆自己完結型**: すべてのツールは隔離されたビルド環境で再現可能にビルドでき、外部クラウドへのテレメトリ送信なしで自立して動作すべきです。

## 🧰 技術スタック・マトリクス

### システム＆プログラミング言語
- **主要言語**: Rust（coreクレート、`no_std`、ベアメタル組み込み）、Modern C++（C++20/23、テンプレートメタプログラミング、SIMD）、Zig（クロスコンパイル環境、ランタイムグルー）、C99/C11（POSIXインターフェース、ドライバ層）。
- **補助・スクリプト**: POSIX Shell、Python 3（ベンチマーク計測、グラフ描画、信号シミュレーション）、Lua 5.4（組み込みエンジン用スクリプト）。
- **アセンブリ**: x86_64、AArch64、ARM Cortex-M（ベアメタル起動コード、コンテキストスイッチプリミティブ）。

### カーネル、組み込み＆開発ツール
- **カーネル・ランタイム解析**: QEMU、GDB / LLDB、perf、valgrind、Linux eBPF、FreeBSD bhyve。
- **コンパイラ・ツールチェーン**: Clang/LLVMツールチェーン、GCCクロスコンパイラ、cargo、ninja、make。
- **ハードウェア・信号解析**: Saleae Logic Pro 16ロジックアナライザ、Siglent SDS1104X-Eオシロスコープ、JTAG/SWDデバッグプローブ（ST-Link、J-Link）、I2C/SPIバス解析。

### プロトコル＆ストレージ
- **バイナリ通信**: ゼロコピーCap'n Proto、FlatBuffers、CAN / UART / UDP上のカスタムバイナリフレーミング。
- **ストレージエンジン**: ログ構造化マージ（LSM）ツリー、メモリマップド（mmap）リングバッファ、Raw NVMeブロック直接ディスパッチ。

## 📈 現在の研究・探究テーマ

- `float-OS`における非同期プロセス間ケイパビリティ・ハンドシェイクのTLA+形式仕様記述。
- リソースが極度に制約されたCortex-M4環境におけるポリフォニック・ウェーブテーブル発振器向けの固定小数点数演算最適化。
- libcにリンクせず、純粋な単独ELFバイナリを直接出力する超軽量セルフホスティング・コンパイラバックエンドの試作。
