# مرحبًا، أنا إيدان فانس (`@float-OS`) 🛠️

```text
  _   _             _             ___  ____  
 | | | | ___ _   _  | |_ ___      / _ \/ ___| 
 | |_| |/ _ \ | | | | __/ _ \    | | | \___ \ 
 |  _  |  __/ |_| | | || (_) |   | |_| |___) |
 |_| |_|\___|\__, |  \__\___/_____\___/|____/ 
             |___/         |_____|            
  "إذا لم يكن البرنامج قادراً على العمل على السيليكون البارد دون كابل شبكة، فهو خدمة وليس برنامجاً."
```

مهندس برمجيات أنظمة ومطور عتاد مقيم في تروندهايم، النرويج. أعمل نهاراً على تصميم مسارات قياس عن بُعد (Telemetry) منخفضة زمن الاستجابة ووحدات اتصال حتمي في الوقت الفعلي؛ وأقضي لياليّ في بناء أنوية دقيقة تجريبية قائمة على القدرات (Capability-based microkernels)، ومُركّبات صوتية خالية من حجز الذاكرة الديناميكي، وأدوات سطر أوامر صغيرة وموثوقة.

أؤمن بالبرمجيات التي تحترم الذاكرة، وتعمل بشكل متوقع تحت الضغط الشديد، وتصمد بعد زوال أطر العمل العابرة.

---

## 🧭 الفلسفة الهندسية

- **انعدام الحجز في المسار الحرج (Zero Allocation in the Hot Path)**: إذا كانت الحلقة الداخلية تستدعي مُخصّص الذاكرة الديناميكي (Heap Allocator)، يُعتبر ذلك خطأً معمارياً حتى يثبت العكس.
- **زمن الاستجابة المتوقع أهم من ذروة الإنتاجية**: النظام الذي يعالج 100,000 طلب/ثانية ولكن بزمن استجابة غير منضبط يصل إلى ثانيتين يُعتبر نظاماً معطلاً في سيناريوهات التحكم الفيزيائي الحقيقية.
- **التوافق الميكانيكي (Mechanical Sympathy)**: افهم كيفية محاذاة أسطر الذاكرة المخبئية (Cache Lines)، وكيف يتنبأ المعالج بالتفرعات، وأين يكمن عنق الزجاجة في متحكم الذاكرة قبل أن تلوم المُترجم (Compiler).
- **العمل دون اتصال أولاً والاستقلالية**: يجب أن تُبنى جميع الأدوات بشكل مستقل تماماً داخل بيئات معزولة، وتعمل بكفاءة دون الحاجة إلى إرسال قياسات إلى خدمات سحابية خارجية.

## 🧰 مصفوفة التقنيات

### الأنظمة ولغات البرمجة
- **اللغات الأساسية**: Rust (حزم core، و`no_std`، والأنظمة المدمجة)، و Modern C++ (معايير C++20/23، وبرمجة القوالب، وSIMD)، و Zig (أدوات الترجمة المتقاطعة وربط وقت التشغيل)، و C99/C11 (واجهات POSIX وتعريفات العتاد).
- **اللغات الثانوية والنصوص**: POSIX Shell، و Python 3 (اختبارات الأداء، والرسوم البيانية، ومحاكاة الإشارات)، و Lua 5.4 (البرمجة النصية داخل المحركات المدمجة).
- **التجميع (Assembly)**: لمعماريات x86_64، و AArch64، و ARM Cortex-M (أكواد الإقلاع والتبديل السياقي).

### النواة، الأنظمة المدمجة وأدوات التطوير
- **تحليل النواة ووقت التشغيل**: QEMU، و GDB / LLDB، و perf، و valgrind، و Linux eBPF، و FreeBSD bhyve.
- **المترجمات وسلاسل الأدوات**: أدوات Clang/LLVM، ومترجمات GCC المتقاطعة، و cargo، و ninja، و make.
- **العتاد وتحليل الإشارات**: محلل المنطق Saleae Logic Pro 16، وراسم الإشارة Siglent SDS1104X-E، ومسابير تصحيح JTAG/SWD (مثل ST-Link و J-Link)، ومراقبة حافلات I2C/SPI.

### البروتوكولات ومحركات التخزين
- **البروتوكولات الثنائية**: Cap'n Proto دون نسخ، و FlatBuffers، وتأطير ثنائي مخصص عبر CAN / UART / UDP.
- **محركات التخزين**: أشجار دمج السجلات (LSM-Tree)، وذاكرة الحلقات المعينة في الذاكرة (mmap)، والتعامل المباشر مع كتل NVMe.

## 📈 مجالات البحث والاستكشاف الحالية

- كتابة مواصفات رسمية دقيقة باستخدام TLA+ للمصافحات غير المتزامنة للقدرات بين العمليات في `float-OS`.
- دراسة تحسينات الحساب بالأرقام الثابتة (Fixed-point) لمذبذبات جداول الموجات متعددة النغمات على معالجات Cortex-M4 محدودة الموارد.
- تجربة بناء مجمّع ذاتي الاستضافة شديد الصغر يُنتج ملفات ELF ثنائية نقية دون ربط مع مكتبة libc.
